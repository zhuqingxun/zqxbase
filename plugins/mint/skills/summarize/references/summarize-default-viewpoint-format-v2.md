# V2.0 默认观点汇总格式样例 (内置)

> 本文档为 mint:summarize 在 `viewpoint_template_path` 字段为空时使用的内置默认格式参考样例。摘自用户 V2.0 实证标准 (某业务组织访谈观点汇总), 已脱敏 + 精简, 仅展示**格式骨架**, 内容主题以实际素材为准。
>
> 给 LLM 的指令: 看完本样例后**严格按其格式风格输出**, 但**禁止把样例内容直接复制到输出中**。

## 样例 1: 多人聚合风格 (≥5 位受访者, 如 internal type)

> 以下展示数字编号 + 加粗主张句 + 综合论证段 + 子主题分类的骨架。

### 【问题 1：公司战略目标的承接】

> - **核心问题：** 目前流程已经建立完善, 但常常听到"看不到未来领袖"的声音。你认为现有干部管理流程哪些环节的差距导致了这个问题?

> - **深度追问：** 假设到今年年底战略目标进展缓慢。从干部管理体系来看, 你认为最可能是哪项工作出现了问题?

#### 战略层面

1. **多数受访者反馈, 战略到干部管理的解码不足, 某业务组织缺乏跨年度延续性的干部管理战略, 团队陷入各自找亮点**。公司战略与干部工作之间缺乏系统化的分解与传导, 各团队普遍围绕高层当下关注的话题快速响应, 难以沉浸式投入见效周期较长的工作。受访者普遍反馈干部规划始终没有清晰答案; 与之相伴的现象是各团队各干各的、各自展示当期产出, **整个组织缺少一件能将全员凝聚在同一目标下的核心事项**。当前许多重点工作实质上是从业绩差距倒推出来的议题, 而非自战略目标分解衔接到干部工作。要真正解决这一断裂, **必须形成一个综合性的解决方案, 并由专人牵头统筹**。

2. **"什么样的干部"这个目标画像在公司层面缺乏清晰锚点, 同一句话对不同人理解差异较大**。公司整体上对需要什么样的人并没有清晰定义——目标本身模糊, 也没有可以共同参照的锚点。诸如"强"这类关键词本身就难以界定, **长期缺乏一套可被衡量的共同标准**, 选拔因此依赖各人凭主观理解。**战场已经发生根本性变化, 不能再沿用运营商时代的标准去衡量 AI 时代所需的领军人物。**

#### 机制层面

3. **层层叠加的踩台阶、基层成功实践、根正苗红筛选条件, 导致把"敢干敢破"的人挡在门外**。受访者普遍感到当前选拔流程上的枷锁正越来越多, **整套机制、层层流程的导向已经更多指向合规而非识别人才**——能被选出来的基本都是绩效过得去、合规性没有问题的中规中矩型干部, 真正能把业务带上新台阶的领袖型人物反而难以浮现。

#### 执行层面

4. **干部选拔的讨论环节管理者"放水", 小妥协累积导致选拔导向被破坏**。AT 选拔的每一层领导在评审时都可能出现这样的潜在心态——"这位候选人也不是完全不能干, 放一次水无关大局"。但同样的松口出现在每一层, 累积下来整个选拔的地基就变得不稳。

## 样例 2: 少人各表风格 (≤4 位受访者, 如 external type)

> 以下展示 `**观点 N:**` + `**延伸观点:**` 编号风格。

### 【问题 1：公司战略目标的承接】

> - **核心问题：** 你认为现有干部管理流程哪些环节的差距导致了这个问题?

**观点 1：公司并不缺少有潜力的人才, 而是缺少给年轻人试错的机会**。受访者认为当前倾向于在岗干部"能干就接着干", 年轻人没有上升通道; 同时干部"之"字型发展的最佳窗口期被错过, 前期SPDT层取消海外经验要求后, 产品线总裁梯队断层成为结构性问题。在选干部的执行层面, 公司存在"说一套做一套"——**干部管理的群体导向到个体审视时每个人都有故事, 最终个体例外累积起来形成群体性现象**。

**观点 2：受访者认为公司干部管理在群体层面已有显著进步**, "把整个群体管住了"。但"一代更比一代强"本质上是个体层面的感知——领导在具体岗位选拔时逐人比较, 差距感格外突出。核心困难有二: 一是选拔基于过去成功经验, 面向个体时难以保证新任必然优于前任; 二是**发现人岗不匹配后缺乏及时调整的魄力**, 往往拖到业务严重受损才换人。

**延伸观点：产品线总裁梯队横向循环项目是一个已跑通的解法样本**

受访者专门介绍了已坚持三四年的"产品线总裁梯队横向循环"项目。该项目三年前由管委会立项, 背景是上一轮选产品线总裁时发现候选人普遍缺海外经验、一线市场成功经验和商业历练, "选起来捉襟见肘"。方案是每年从下属六个产品线各派至少两人到一线销服关键岗位历练。**受访者认为这类"长周期、代际接力"的专项项目可视为公司战略意志与前瞻性挑战的一种系统化回应。**

## 样例 3: 不分子主题的简单列法 (观点数 < 6 时)

### 【问题 6：团队氛围】

> - **核心问题：** 你对当前部门的团队氛围评价如何?

> - **深度追问 1：** 你认为影响氛围最大的几个因素是什么?

> - **深度追问 2：** 你有何改进建议?

1. **这里大家都很客气, 表面没矛盾, 是乐乐呵呵的人际相处, 但缺乏发自内心的沟通, 这不该是追求的团队氛围**。受访者认为当前组织分割过细, 彼此之间是维持着表面的乐乐呵呵属性, 表层和气难以构成真正意义上的团队氛围。**深层的碰撞偏少, 发自内心的沟通不够, 交流更多停留在表面**; 二层主管之间同样以任务驱动为主, **务虚性质的碰撞偏少**。

2. **物理距离与紧绷感是团队氛围两个可以改进的点**。一是物理距离: **团队坐在两个地方, 对交流产生了一些障碍**——每个人所做的工作, 冰山下的东西永远占绝大部分, 隔开之后彼此理解起来更费力。二是整体氛围有点紧张、有点紧绷: 部门一把手要求高、节奏急, 大家因此紧绷。**建议部门主管也给团队更多的空间, 不要怕下属说错、犯错**。

## 格式特征总结 (LLM 须遵循)

1. **章节层级**:
   - 文件总标题 `# {工作区名}_{产物名}_{type}` (一级 #)
   - 问题章节 `### 【问题 N：标题】` (三级 ###, 全角【】, 全角冒号 ：)
   - 子主题 `#### 战略层面` (四级 ####, 按需分组)

2. **前置 blockquote**:
   - 紧跟问题章节标题, 用 `> - **核心问题：** ...` 列出提纲原文 (注意全角冒号)
   - 多个追问分别列: `> - **深度追问：** ...` `> - **极限施压：** ...`
   - blockquote 行间空行分隔 (markdown 渲染要求)

3. **观点编号风格 (按受访者数量)**:
   - 多人聚合 (≥5): `1. **多数受访者反馈, xxx**` (数字 + 加粗主张)
   - 少人各表 (≤4): `**观点 1:** xxx` (观点编号, 注意半角冒号 OK 但 V2.0 实证多用全角)
   - 延伸观点: `**延伸观点：** xxx` (用于同一受访者的额外观点)

4. **综合论证段**:
   - 一个观点 = 一段 (段内不分换行)
   - 关键短语保留加粗 (如「事成放前面、人爽放后面」)
   - 内嵌建议加粗强调 (如「**必须 ...**」)
   - 句号结尾

5. **问题间分隔**: 用 `---` 三连横线水平分隔

6. **禁止 (V2.0 严格规范)**:
   - ❌ 受访者编号 (`受访者 A`、`受访者_01`、`01_李玉蕾`)
   - ❌ 原声引号引用 (`"..."` 长句直接引用) [仅产物 2 在每观点末单独原声段中允许]
   - ❌ 真实姓名 (从原稿反推)
   - ❌ "(主流观点)/(次主流观点)/(次要观点)" 等分级标签 (用户明确反对)
   - ❌ "共识/分歧/附加视角" 三段式框架 (旧 v2 退化格式)
   - ❌ "X 认为...Y 则认为..." 对峙式分歧写法 (V2.0 是融合, 不是对峙)

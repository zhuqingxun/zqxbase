# 教案生成模板（aixue-math:generate 的目标产物结构）

本文件是 `aixue-math:generate` 的**目标产出结构规约**，基于真实优质教案样例归纳。生成时严格遵循本结构，不增不减（明确 SKIP 的章节除外）。

## 来源样例

工作区共享资源目录 `<shared_dir>/04_教案样例/samples/`（`shared_dir` 由 `workspace.yaml` 配置）下的两份教学设计方案 PDF：
- 《一米有多长》（北师大版 二上）
- 《公顷、平方千米》（北师大版 五上）

> 样例 PDF 属教师自备资料，不随插件分发；本模板只归纳其**结构规约**。

## 章节生成细则

### 二、教材分析

**必须生成**：

- 课标要求（依据义务教育数学课程标准 2022 版摘录相关段）
- 教参目标要求
- 教材编排意图（从 textbook 提取结果中归纳课程逻辑链）
- 显性知识与隐性知识（从 knowledge.md 读取）
- 知识结构化图（**文字描述** + 用 Mermaid / ASCII 画图，实际图片由教师替换）

**必须跳过（SKIP）**：

- ❌ **其他版本教材对比（北师大/人教/苏教）** — 本项目**明确不生成**。理由：跨版本对比需要同步的 3 套教材原图分析，AI 无法凭空生成，且用户明确表示未来的教案都不包含此节。生成时**连章节标题都不出现**。

### 三、学情分析

**可以生成**：

- 学情分析正文（学生已有知识基础 + 可能困难）
- 建议的前测/访谈问题单（供教师实际施测）

**必须标注"待补充"**：

- 前测数据统计图表 —— AI 无法伪造真实数据，在该位置输出："> 📊 **待教师补充**：请在实际施测 N 份问卷后，将正确率统计图填入此处。"

### 九、学习效果评价

**可以生成**：

- 效果评价测试题（题干 + 考查知识点及设计意图）—— 基于教学目标逐题设计

**必须标注"待补充"**：

- 后测数据分析 —— 与前测同理，标注"待教师授课后补充"

### 十、教学预设过程（核心章节）

**这是最值钱也最难生成的章节**。产出要求：

1. **主要环节与时间分配**：3-5 个主环节（触发 / 追究 / 提升 / 总结），用 Markdown 清单 + 时间分配
2. **每个环节的 4 列表格**，列字段：
   - **教学环节**（教师的提问或活动）
   - **学生活动及预设**（预设 1、预设 2、预设 3 —— 学生可能的反应，至少 2 条）
   - **教师调控及重难点处**（针对每条预设的应对策略）
   - **评价观测点**（教师观察学生是否达到目标的可操作指标）
3. **每个环节开头写 `【环节目标】`**，结尾写 `设计意图：...`

**生成关键**：学生预设要符合对应年级的心理/认知特征，不能凭空编造。参考 knowledge.md 中的"学情预判"小节。

### 十一、板书设计

生成**文字版板书描述**：

```
板书布局（从左到右）：
- 左侧：核心概念写字区（如 "周长 = 一周的长度"）
- 中间：学生生成区（留白，课堂上填）
- 右侧：算法 / 公式区
```

同时输出一段话："建议教师根据此布局绘制实际板书图，或拍照上课后补入本教案。"

## 生成顺序建议

按 11 节顺序生成 **不** 是最优，推荐的内部生成顺序：

1. 先写 一（教学内容）和 四（教学目标）—— 框定本课内容和目标
2. 再写 二（教材分析）+ 三（学情分析）—— 基于 textbook.md + knowledge.md 抽取
3. 再写 五/六（重难点）—— 从教学目标推导
4. 再写 七（方法）+ 八（资源）—— 从 knowledge.md 教学建议部分抽取
5. 再写 十（教学预设过程）—— **最核心**，基于 textbook.md 的页面结构 + knowledge.md 的问题串 + 样例的 4 列表结构
6. 再写 九（评价）+ 十一（板书）—— 围绕教学目标闭环
7. 最后输出目录和封面

## 硬约束（生成时检查清单）

- ❌ 不生成"其他版本教材对比"章节
- ❌ 不伪造前测/后测数据
- ✅ 每个教学环节必须有"环节目标 + 教学环节 + 预设 + 调控 + 观测点 + 设计意图"六要素
- ✅ 学生预设必须至少 2 条（一条正常回答 + 一条可能错误或不同思路）
- ✅ 使用的课本页码/插图必须能在 textbook.md 中找到对应 fig_pXX_K 锚点
- ✅ 所有数学公式用 LaTeX
- ✅ 使用半角标点（）[]
